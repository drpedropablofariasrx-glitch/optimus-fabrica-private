# CAMPOS_INTERFAZ_TORAX

Al elegir Tórax, la interfaz muestra controles regionales para:

- Tipo de estudio.
- Contexto clinico.
- Protocolo.
- Contraste.
- Comparacion disponible.

Los valores acompañan a generar, revalidar y guardar. Se restauran al abrir un caso toracico y se persisten con el registro regional. En las otras siete regiones los controles no se muestran ni modifican su flujo.
