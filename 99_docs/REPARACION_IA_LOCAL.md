# Reparacion local

Ejecute `REPARAR_OPTIMUS_IA.bat` para comprobar y recuperar solo componentes ausentes o corruptos. Un GGUF se considera valido cuando coincide el nombre oficial, supera el umbral de tamano y comienza por la firma `GGUF`. La reparacion no modifica OPTIMUS, prompts, validadores, datasets, casos ni Gold.
