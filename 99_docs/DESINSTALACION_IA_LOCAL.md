# Desinstalacion local

`DESINSTALAR_OPTIMUS_IA.bat` permite retirar `Llama`, `Model`, `Both`, `Temporary` o `Logs`, siempre tras confirmacion. Solo admite rutas contenidas en la raiz de OPTIMUS y rechaza enlaces. No elimina la aplicacion, datos clinicos, datasets, casos, Gold, prompts ni validadores.

Ejemplo no interactivo: `./DESINSTALAR_OPTIMUS_IA.ps1 -Target Temporary -NonInteractive`.
